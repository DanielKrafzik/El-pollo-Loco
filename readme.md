# Sharkie – 2D Browser Game

Sharkie is a fun and interactive 2D browser game built with JavaScript. Players control a character in an underwater world, avoiding enemies and collecting items while exploring a dynamic environment.

The project focuses on game logic, animations, and responsive gameplay mechanics.

---

## 🌐 Live Demo

👉 https://danielkrafzik.com/portfolio/sharkie

## ✨ Features

* Interactive 2D gameplay
* Smooth character movement and animations
* Collision detection system
* Enemy AI behavior
* Collectible items and scoring system
* Sound effects and visual feedback
* Responsive design

## 🛠️ Tech Stack

* JavaScript (Vanilla)
* HTML5
* CSS3

## ⚙️ Installation

To run the project locally:

```bash
git clone https://github.com/DanielKrafzik/El-pollo-Loco.git
cd El-pollo-Loco
```

Then open the `index.html` file in your browser.
